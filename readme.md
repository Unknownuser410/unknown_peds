# 🚀 FiveM Ped Manager – Spieler-Peds dauerhaft speichern!

Mit diesem Script kannst du Spieler-Peds ändern und inklusive Kleidung über Neustarts hinweg speichern! 🎭👕
- Peds individuell setzen und speichern.
- Kleidung bleibt nach Neustarts erhalten.
- Einfaches Command-basiertes System.

# 📌 Voraussetzungen (Dependencies)
- ESX
- Skinchanger

# 🛠️ Installation
### Addon-Peds nutzen:
1️⃣ **Streaming-Dateien** in den `stream`-Ordner packen.
2️⃣ **.meta-Dateien** in den `meta`-Ordner verschieben.
3️⃣ `.meta`-Datei in der `fxmanifest.lua` registrieren.

### Script starten:
- Füge das Script in den `resources`-Ordner ein.
- Stelle sicher, dass alle Abhängigkeiten installiert sind.
- Starte das Script in der `server.cfg` mit:
  ```cfg
  ensure dein_script_name
  ```

# 🚀 Befehle

### 🎭 Ped setzen
Setzt einem Spieler ein bestimmtes Ped:
```text
/setped (ID) (Pedname aus Peds.meta)
```

### 🔄 Ped zurücksetzen
Setzt das Ped eines Spielers auf das Standard-Ped (männlich/weiblich):
```text
/setped (ID) (male oder female)
```

# Fazit
✨ Perfekt für RP-Server, um Spielern individuelle Charaktere zu ermöglichen! 🚀
